# XXD Panel 052｜浮岛纸艺微缩景观生产提示词

只处理当前新任务明确提供的这一张源照片。私下锁定主体身份、剪影、比例、姿态、方向、动作、结构、叙事关系、环境特征与综合色温，至少保留三个源图专属线索；不得借用其他输入、旧输出或样张。

## 审美重构

不要机械复制照片。把最具识别度的主体和少量真正强化身份与环境的元素重构为精致手工纸艺微缩模型，材料可包括纸、卡纸、软陶与薄木片。让它们自然坐落在一条修长、轻盈、横向悬浮的景观基座上，形成具有真实手工触感、空气感冷蓝配色、微距摄影光影与大量留白的高级微缩艺术装置。

严格遵循这条因果链：锁定身份、剪影、姿态、方向与叙事关系 → 保留三个识别线索 → 选择一个主角与少量有依据的辅助元素 → 重构为纸、卡纸、软陶和薄木微缩模型 → 放置在一条修长横向悬浮景观带上 → 建立尺度纵深、层叠遮挡、安静左右平衡与真实接触 → 用亲密微距摄影光线表现材质 → 用极浅底色和大量留白包围 → 将一个签名般短标题放在景观带下方或沿其走势。

## 硬性视觉要求

- 从剪影、比例、姿态、方向、动作、开口、结构、颜色、材质或关系中保留至少三个源图专属线索；主角必须一眼可认。
- 建立一个视觉重量最大的主角，只保留少量源图相关的辅助模型。植物、道路、水面、灯、交通工具、人物、鸟、云或日常细节只有在强化身份或环境时才可出现。
- 所有元素坐落于一条长、窄、轻盈的横向悬浮景观基座。根据原图调整高度、深度、密度、间距与左右平衡；整体大致居中但不得机械对称。
- 通过尺度变化、层叠遮挡与更安静的前后景小元素建立纵深；主角最重，辅助元素更小、更轻，不得建立第二中心。
- 真实呈现纸纤维、折叠边、切割痕、层叠厚度、微粗边缘和细小手工不完美；材料包括纸、卡纸、软陶和薄木，拒绝光滑塑料 CGI。
- 以浅粉蓝、雾蓝、天空蓝和空气感冷蓝为主，以象牙白、奶油白、浅米色、柔和灰绿、鼠尾草绿和建筑中性色平衡，只允许少量 dusty rose 或 muted blush 点缀。拒绝灰脏、过黄与糖果色。
- 使用柔和自然漫射光与细腻阴影，像亲密的微距摄影一样表现体积和触觉；背景为柔白或极浅色，并保留大面积干净负空间。

## 文案与语言

服从已经确认的自动文案、准确自定义文案或无文字模式，以及目标语言／地区。只从地点、主体身份、主题或情绪中提炼一个短标题；文字小、精致、克制并带轻微手写气质，优先放在横向景观带下方留白，也可沿基座轻微弯曲或与模型空间互动。它应像艺术家签名而不是商业标题，不加长段解释。用户准确文案逐字保留；无文字模式不得出现字母、字符、数字、标签或伪文字。

## 模式与验收

严格服从附加的 `OUTPUT MODE`、`FINAL SIZE` 与 `DESIGN FRAME`。双联模式只生成设计半幅；纯设计和壁纸不显示原照片、接缝或预留摄影区。每张壁纸按设备重新构图，不裁切其他设备成果。连贯套装始终共同参考原照片与同一张批准定调图，绝不串联衍生图。

拒绝：塑料 CGI、玩具模型展示、儿童手工感、通用微景观、无意义装饰、过度复杂、机械对称、过度可爱、灰脏、偏黄、糖果色、硬质商品灯光和电商陈列。同时拒绝 logo、水印、色卡、UI、设备样机、无依据事实、伪外语和不可读文案。

任何硬性条件失败都必须纠正位图资产，不得以程序绘图、SVG、HTML、Canvas、3D 代码或后期文字覆盖伪造成品。
