# XXD Panel 052 原始风格提示词

请将我上传的每一张照片分别制作成一张独立的高级设计海报。不要制作多图拼贴；每张照片都应单独输出。整体采用 3:4 竖版构图，严格分成上下两个等高区域，上下各占画布的 50%。

上半部分保留原始照片，保持主体结构、真实质感、自然光影和原有色彩氛围。只进行轻微、精致的高级摄影调色，使画面具有艺术杂志、独立出版物或画廊展览中的编辑摄影质感。为适配所需画幅，可以自然扩展天空、地面或周围环境，但不得拉伸、扭曲或改变主要主体。

下半部分提取照片中最具识别度的主体、轮廓、姿态与叙事关系，将其重新诠释为精致的微缩 3D 纸艺场景。不要机械复制照片，而应把主要主体和少量最能强化其身份与环境特征的元素，转化为由纸张、卡纸、软陶、薄木片等材料手工制作的微型模型，并自然组织在一条狭长、轻盈、悬浮的景观基座上。主要主体必须一眼可辨，其他元素只能作为叙事陪衬。可根据原图加入植物、道路、水面、灯具、交通工具、人物、飞鸟、云朵或其他具有代表性的日常细节，但每个新增元素都必须与原始主题真实相关，避免无意义的装饰堆砌。

构图以一个主要主体、一条横向微缩景观带和大面积留白为基础。根据主体的体量、方向与空间关系，调整高低、前后、间距、疏密和左右视觉重心，使场景像一件被精心策展的微型艺术装置。通过尺度变化、层叠遮挡以及小型前景与背景元素建立纵深。主要主体承担最大的视觉重量，辅助模型保持更小尺度和更低视觉权重。整体以居中关系为基础，但不过度对称，保持轻盈、精致、安静的视觉节奏。

继续使用柔和、通透、略微去饱和的高级配色。以浅粉蓝、雾蓝、天空蓝和空气感冷调蓝建立主要氛围，以象牙白、奶油白、浅米色、柔和灰绿、鼠尾草绿和建筑中性色保持平衡，只用少量灰粉色或柔和腮红色作为点缀。颜色应柔和但干净，避免灰脏、过度泛黄或糖果色。让不同纸层之间的细微色差自然形成空间分隔与纵深。

强调真实的手工材质感。可以清晰看到纸张纤维、折边、切口、层叠厚度、轻微毛边和细小的手作误差。使用柔和、自然的漫射光与细腻阴影，表现微缩模型真实的体积与层次，并具有微距摄影般亲密、可触摸的质感。背景保持柔和白色或极浅色，大面积干净留白，使整个下半部分像一张经过精心拍摄的高级手工旅行明信片。

文字也应融入微缩纸艺语言。从照片的地点、主体身份、主题或情绪中提炼一个简短标题，不限定必须是城市名称。使用小型、精致、略带手写感的字形。标题优先放在微缩景观带下方的留白区域；适合时也可以轻微弯曲、沿基座排列，或与微缩场景形成空间互动。文字保持极少、优雅、克制，不加入长段说明，让标题更像艺术家的签名，而不是商业标题。

整体视觉应结合微缩场景、手工纸艺、趣味 3D 插画与高级旅行明信片的品质：轻盈、温柔、精致、可触摸、富有日常生活气息，同时保持清晰的设计秩序与充足的呼吸空间。无论原图是人物、动物、植物、建筑、器物、交通工具还是自然景观，都应在真实摄影世界与手工微缩世界之间保持清晰而巧妙的视觉对应。避免塑料感 3D 渲染、玩具感、儿童手工感、过度复杂、过度可爱，以及电商产品展示感。
